# Key Sender - Multi-Device Remote Key Controller

様々なデバイス（スマートフォン、タブレット、PC等）からMacにキーイベントを送信できるWebSocketベースのリモートコントローラーです。

## 📱 対応デバイス

### クライアント側（キー送信側）
- **スマートフォン**: iPhone、Android
- **タブレット**: iPad、Android タブレット
- **PC/ノートPC**: Windows、Mac、Linux
- **ブラウザ**: Chrome、Safari、Firefox、Edge

### サーバー側（キー受信側）
- **Mac**: macOS 10.14以降（アクセシビリティ権限が必要）

## 🚀 特徴

- **デバイス自動検出**: UserAgentと画面サイズから自動的にデバイスタイプを判定
- **レスポンシブデザイン**: スマートフォンから大画面まで最適化されたUI
- **リアルタイム通信**: WebSocketによる低遅延通信
- **タッチ対応**: モバイルデバイスでの操作性を重視
- **接続安定性**: タイムアウト設定と詳細なエラーハンドリング
- **デバイス情報送信**: 接続時にデバイス詳細情報を自動送信

## 📋 必要な環境

### Mac側（サーバー）
- Python 3.7以降
- 必要なライブラリ:
  ```bash
  pip install websockets pynput pyobjc-framework-Quartz
  ```

### クライアント側
- 現代的なWebブラウザ（WebSocket対応必須）
- 同一WiFiネットワーク接続

## 🛠️ インストールと設定

### 1. Mac側の設定

1. **依存関係のインストール**:
   ```bash
   pip install websockets pynput pyobjc-framework-Quartz
   ```

2. **アクセシビリティ権限の設定**:
   - システム環境設定 → セキュリティとプライバシー
   - プライバシー → アクセシビリティ
   - ターミナルまたはPythonを追加してチェック

3. **サーバーの起動**:
   ```bash
   python3 main.py
   ```

### 2. クライアント側の設定

1. **MacのIPアドレスを確認**
   - サーバー起動時にコンソールに表示されるIPアドレスをメモ

2. **Webブラウザでアクセス**
   - `index.html` ファイルをWebブラウザで開く
   - または、ローカルサーバーを立ててアクセス

3. **接続設定**
   - WebSocket URL欄に `ws://[MacのIPアドレス]:8080` を入力
   - デバイスタイプが自動検出されるが、手動で変更も可能
   - デバイス名を設定（自動生成されるが変更可能）

## 🎮 使用方法

### 基本操作

1. **接続**:
   - 設定を確認して「接続」ボタンをクリック
   - 接続成功後、Mac一覧が表示される

2. **Mac選択**:
   - 利用可能なMacリストから送信先を選択

3. **キー設定**:
   - キー1、キー2に送信したいキーを設定
   - 例: `space`, `escape`, `cmd+c`, `f1`

4. **キー送信**:
   - 大きなボタンをタップ/クリックしてキーを送信

### 対応キー形式

- **単一キー**: `a`, `1`, `space`, `enter`, `escape`
- **修飾キー付き**: `cmd+c`, `ctrl+shift+a`, `option+f4`
- **ファンクションキー**: `f1`, `f2`, ..., `f12`
- **特殊キー**: `up`, `down`, `left`, `right`, `home`, `end`

## 🔧 トラブルシューティング

### 接続できない場合

1. **ネットワーク確認**:
   - デバイスとMacが同じWiFiに接続されているか確認
   - MacのIPアドレスが正しいか確認

2. **ファイアウォール設定**:
   - MacのファイアウォールでPythonが許可されているか確認
   - ポート8080が開いているか確認

3. **権限確認**:
   - アクセシビリティ権限が正しく設定されているか確認

### キーが送信されない場合

1. **Mac選択確認**:
   - 送信先Macが選択されているか確認

2. **キー形式確認**:
   - キー名が正しい形式で入力されているか確認

3. **権限再確認**:
   - アクセシビリティ権限を一度無効化して再度有効化

## 📊 技術仕様

### 通信プロトコル
- **WebSocket**: RFC 6455準拠
- **メッセージ形式**: JSON
- **ポート**: 8080（変更可能）

### サポートされるメッセージタイプ
- `register`: デバイス登録
- `send_key`: キー送信
- `ping/pong`: 接続確認
- `heartbeat`: ハートビート

### セキュリティ
- ローカルネットワーク内通信のみ
- TLS/SSL暗号化なし（ローカル用途）
- 認証機能なし

## 📝 ログとデバッグ

- **ブラウザログ**: 開発者ツールのコンソール
- **詳細診断**: 接続時に自動実行
